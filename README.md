*Official web portal and documentary repository (CEDOC) for a cultural organization with a 20-year history, featuring robust content management, multimedia streaming, and workshop administration.*

- **Key Architecture & Challenges:** 
  - Designed a decoupled architecture deploying the frontend on **Vercel** and the backend on **Render**.

### 💰 Pirwa — Soberanía Financiera en tu Bolsillo
*A privacy-first, zero-friction mobile application designed for local-first accounting and inventory tracking, tailored specifically for independent businesses and workshops.*
- **Key Architecture & Challenges:**
  - **Local-First Paradigm:** Built a fully offline-capable architecture using `expo-sqlite` where data processes entirely on-device, drastically improving speed and security.
  - **Robust State & Validation:** Implemented global state management with **Zustand** and strict data validation layers using **Zod**.
  - **Advanced Features:** Engineered a customized numeric keyboard for fast transaction recording (<15 seconds), dynamic 6-month data visualization dashboards, automated PDF reporting, and secure end-to-end encrypted backup integration with Google Drive.
